# 유용래

 ### 컴퓨터학 · 정보보안 · 정보관리

 컴퓨터학을 기반으로 소프트웨어와 정보보안 기술을 학습하고 있으며,\
 정보의 생성부터 저장, 처리, 보호, 활용에 이르는 전반적인 과정에 관심을 가지고 있습니다.

 특히 **소프트웨어 기술, 데이터 관리, 정보보안의 관계**를 이해하고 이를 실제 시스템과 프로젝트에 적용하는 것을 목표로 공부하고 있습니다.

 배운 내용을 단순히 습득하는 것에 그치지 않고,\
 직접 구현하고 문제를 해결하며 그 과정과 결과를 문서화하는 것을 중요하게 생각합니다.

 ## 정보보안 학습

 정보보안을 공부하면서 다음과 같은 질문을 중심으로 학습하고 있습니다.

 ### 시스템은 어떻게 동작하는가?

 먼저 시스템의 구조와 데이터의 흐름을 이해합니다.

 ### 어디에서 문제가 발생할 수 있는가?

 시스템의 취약한 지점과 보안상 발생할 수 있는 문제를 분석합니다.

 ### 어떻게 보호할 수 있는가?

 취약점을 줄이고 안전한 시스템을 설계하는 방법을 학습합니다.

 ### 실제로 안전한가?

 구현된 보안 기능이 의도한 대로 동작하는지 테스트하고 검증합니다.

 궁극적으로는 단순히 보안 도구를 사용하는 것을 넘어,\
 **시스템의 구조와 보안 문제를 함께 이해할 수 있는 역량**을 갖추는 것을 목표로 합니다.
